# HSE-Physical-Activity-Analysis
This project utilizes the Health Survey for England (HSE) 2022 dataset to investigate whether physiological and lifestyle factors, such as BMI and daily sedentary time, are stronger predictors of physical activity habits than traditional socio-economic demographics. By engineering a composite target variable and implementing a dual-stream preprocessing pipeline, this research evaluates and compares the predictive performance of LightGBM, Random Forest, and a Multi-Layer Perceptron (MLP) neural network. The project concludes by demonstrating that gradient boosting architectures like LightGBM provide superior classification accuracy for noisy, heterogeneous survey data, and provides an interactive ipywidgets deployment to facilitate real-time clinical inference based on hypothetical patient metrics.
